# Projeto NexTech Solutions

Site institucional de uma empresa de tecnologia fictícia (NexTech Solutions), especializada em desenvolvimento web, computação em nuvem, consultoria em TI e suporte técnico.

Projeto desenvolvido como Atividade Prática de Desenvolvimento Colaborativo com Git e GitHub.

## Equipe

- **Lucas** — Gerente do Projeto — Header, menu de navegação, seção inicial (Hero) e seção "Sobre nós" — branch `feature/header-hero-sobre`
- **Murilo** — Desenvolvedor — Seção de Serviços (cards), seção de Contato (formulário) e Footer — branch `feature/servicos-contato`

## Estrutura do projeto

```
projeto-nextech/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Fluxo de trabalho utilizado

```
main → branch individual → commits → push → Pull Request → revisão → merge na main
```

Cada integrante trabalhou exclusivamente em sua própria branch e integrou o código à `main` somente após a abertura e revisão de um Pull Request.

## Como visualizar o site

Basta abrir o arquivo `index.html` em qualquer navegador, ou clonar o repositório:

```
git clone <url-do-repositorio>
cd projeto-nextech
```
